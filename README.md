# Full Stack Product Manager

## English

A full-stack application for managing products with a modern frontend and robust backend architecture.

### Project Overview

This project is a full-stack product management system built with modern web technologies. It consists of two main components:

- **Frontend**: A React-based user interface for product management
- **Backend**: A Node.js server with Express.js for handling API requests

### Project Structure

```
.
├── client/          # Frontend React application
├── server/          # Backend Node.js application
└── README.md        # Project documentation
```

### Prerequisites

Before you begin, ensure you have the following installed:
- Node.js (v14 or higher)
- npm or yarn
- Git

### Getting Started

1. Clone the repository:
```bash
git clone https://github.com/yourusername/full-stack-product-manager.git
cd full-stack-product-manager
```

2. Install dependencies for both frontend and backend:
```bash
# Install frontend dependencies
cd client
npm install

# Install backend dependencies
cd ../server
npm install
```

3. Start the development servers:
```bash
# Start the backend server (from server directory)
npm run dev

# Start the frontend development server (from client directory)
npm start
```

### Development

The project is structured to allow independent development of frontend and backend components. Each part has its own package.json and can be developed separately.

- Frontend development happens in the `client` directory
- Backend development happens in the `server` directory
